Interview Answer
"For each technology stack, the build system manages dependencies differently. Java uses Maven or Gradle with dependencies defined in pom.xml or build.gradle and cached in ~/.m2/repository or ~/.gradle. Node.js uses npm, Yarn, or pnpm with dependencies in package.json and lock files like package-lock.json, cached in ~/.npm. Python typically uses pip with requirements.txt or pyproject.toml, and packages are cached in ~/.cache/pip. Go uses Go Modules with go.mod and go.sum, caching modules under ~/go/pkg/mod. .NET uses NuGet with dependencies declared in .csproj files and caches packages in ~/.nuget/packages. In Jenkins, we persist these cache directories on build agents or mount them as persistent volumes for Kubernetes-based agents, and we often use a repository manager like Nexus or Artifactory to proxy and cache external dependencies for faster and more reliable builds."
